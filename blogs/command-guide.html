1. Temel komutlar ve gezinme

2. Dosya yönetimi, kopyalama, taşıma ve arşivleme

Bu bölümde; dosya ve klasörleri kopyalama, taşıma, yeniden adlandırma, arşivleme işlemleri için kullanılan temel terminal komutları yer alır.

2.1. Dosya ve Klasör Kopyalama

İşlemWindows CMDPowerShellmacOS / LinuxAçıklama
Dosya kopyalacopy kaynak hedefCopy-Item kaynak hedefcp kaynak hedefBelirtilen dosyayı başka dizine kopyalar.
Klasör kopyalaxcopy kaynak hedef /s /eCopy-Item kaynak -Destination hedef -Recursecp -r kaynak hedefAlt klasörleri dahil kopyalar.
Kopyalama işlemini doğrulaxcopy /vCopy-Item -Verbosecp -vKopyalanan dosyaları ekranda gösterir.

2.2. Dosya ve Klasör Taşıma

move, mv ve Move-Item komutları, dosya veya klasörleri yeni konuma taşımak için kullanılır.

2.3. Arşivleme (Sıkıştırma)

Linux ve macOS'ta tar, zip, gzip; Windows'ta ise Compress-Archive veya PowerShell destekli komutlar kullanılır.

  • zip -r hedef.zip klasor - ZIP arşivi oluşturur.
  • unzip dosya.zip - ZIP arşivini açar.
  • tar -czvf yedek.tar.gz klasor - TAR + GZIP arşiv oluşturur.

2.4. Dosya Senkronizasyonu

robocopy ve rsync gibi komutlar dosyaları hedef dizinle senkronize eder.

rsync -av --delete kaynak/ hedef/

2.5. Geçici Dosyalar, Loglar ve Yedekler

  • find . -name "*.tmp" -delete - Tüm geçici dosyaları siler.
  • find /var/log -type f -mtime +7 -delete - 7 günden eski logları temizler.
  • du -sh * - Klasör boyutlarını listeler.

2.6. Parametre Mantığı

ParametreAçıklama
-r, /sAlt dizinleri dahil et
-f, /y, /qOnay sormadan işlemi yap
-vAyrıntılı çıktı
-aArşiv modu
--deleteHedefte olmayan dosyaları sil

2.7. Kullanışlı Kombinasyonlar

  • cp -rav kaynak hedef - Alt dizinleri dahil kopyalar.
  • rsync -av --delete kaynak hedef - Dizinleri senkronize eder.
  • tar -czvf yedek.tar.gz klasor - Sıkıştırılmış arşiv oluşturur.

3. Dosya izinleri, sahiplik ve erişim yönetimi

Bu bölüm, kullanıcı izinlerini yönetmek, dosyaların kim tarafından okunabileceğini veya değiştirilebileceğini belirlemek için kullanılan terminal komutlarını kapsar. Windows, macOS ve Linux'ta yetki sistemi farklı olsa da temel mantık aynıdır: okuma (read), yazma (write), çalıştırma (execute) izinleri.

3.1. Kullanıcı ve Grup Kavramı

KavramAçıklamaÖrnek
User (kullanıcı)Sistemde oturum açan kişiwhoami → geçerli kullanıcı
Group (grup)Kullanıcıların toplandığı erişim grubugroups → ait olunan gruplar
Owner (sahip)Dosyayı oluşturan kişils -l çıktısında ilk sütun

3.2. İzinleri Görüntüleme

Linux/macOS ve Windows için izin görüntüleme komutları:

  • ls -l - Dosya izinlerini listeler.
  • stat dosya.txt - Dosya hakkında detaylı bilgi verir.
  • icacls dosya.txt - Windows'ta dosya izinlerini listeler.
  • Get-Acl dosya.txt - PowerShell ACL detaylarını gösterir.
İpucu: -rwxr-xr-- biçimi Linux'ta izinlerin kısa özetidir. İlk karakter türü (- = dosya, d = dizin), ardından kullanıcı, grup ve diğer kullanıcı izinleri gelir.

3.3. Dosya İzinlerini Değiştirme (chmod)

  • chmod izin dosya - Dosya veya klasör izinlerini değiştirir (chmod 755 script.sh).
  • icacls dosya /grant kullanıcı:F - Kullanıcıya tam yetki verir (Windows).

Sayısal izin sistemi (Linux/macOS):

RakamAnlamıAçıklama
7rwxokuma + yazma + çalıştırma
6rw-okuma + yazma
5r-xokuma + çalıştırma
4r--sadece okuma

3.4. Sahiplik (chown) ve Grup Atama (chgrp)

  • chown kullanıcı dosya - Dosya sahibini değiştirir (chown ali belge.txt).
  • chown kullanıcı:grup dosya - Sahip ve grubu birlikte değiştirir.
  • chgrp grup dosya - Sadece grubu değiştirir.
  • icacls dosya /setowner kullanıcı - Windows'ta sahip atama yapar.

3.5. Yalnız Okunabilir / Yürütülebilir Dosyalar

AmaçLinux/macOSWindowsAçıklama
Dosyayı sadece okunabilir yapchmod 444 dosya.txtattrib +R dosya.txtDosya değiştirilemez hale gelir.
Script çalıştırma izni eklechmod +x script.sh-Script'i çalıştırılabilir hale getirir.

3.6. Erişim Listesi (ACL) Komutları

PlatformKomutAçıklamaÖrnek
Linuxgetfacl dosyaDosyanın ACL izinlerini gösterirgetfacl belge.txt
Linuxsetfacl -m u:ali:rwx dosyaAli'ye özel izin tanımlarsetfacl -m u:ali:rwx belge.txt
Windowsicacls dosya /grant ali:FAli'ye tam erişim veriricacls belge.txt /grant ali:F

3.7. İzin ve Sahiplik Kombinasyon Örnekleri

  • chown -R ali:admin proje/ - Alt dizinlerle birlikte sahipliği değiştirir.
  • chmod 700 gizli.txt - Sadece sahip erişebilir.
  • setfacl -m u:veli:rw dosya.txt - Veli'ye okuma-yazma izni verir.
  • icacls dosya.txt /remove user - Windows'ta erişimi kaldırır.

3.8. Parametre ve Kısaltma Tablosu

ParametreAçıklama
-RAlt dizinleri dahil et (recursive)

3.9. Kısa Örnek Rehberi

  • ls -l - İzinleri görüntüle
  • chown kullanıcı dosya - Sahipliği değiştir
  • chmod +x script.sh - Script'i çalıştırılabilir yap
  • getfacl dosya - ACL listele
  • setfacl -m u:ali:rwx dosya - ACL izin ekle
Bölüm Özeti: Bu bölümde chmod, chown, icacls, setfacl gibi komutlarla dosya izinleri ve sahipliği yönetmeyi öğrendin. Artık dosya erişimlerini güvenli şekilde düzenleyebilirsin.

4. Sistem bilgisi, kaynak yönetimi ve performans

Bu bölüm, bilgisayarın donanım, sistem, ağ ve kaynak durumunu terminal üzerinden izlemek ve yönetmek için kullanılan temel komutları kapsar. Sistem yöneticileri ve geliştiriciler için kritik araçları içerir.

4.1. Genel Sistem Bilgisi Komutları

İşlemWindows CMDPowerShellmacOS / LinuxAçıklama
Sistem bilgisisysteminfoGet-ComputerInfouname -aİşletim sistemi sürümü, mimari ve detaylar.
Bilgisayar adıhostnamehostnamehostnameCihazın ağ üzerindeki adını gösterir.
Kullanıcı adıecho %USERNAME%$env:USERNAMEwhoamiOturum açan kullanıcıyı gösterir.
Çalışma süresinet stats srv(get-date) - (gcim Win32_OperatingSystem).LastBootUpTimeuptimeSistemin açık kalma süresi.

4.2. Disk ve Bellek Bilgisi

  • df -h - Disk kullanımını insan okunabilir biçimde gösterir.
  • free -h - RAM durumu.
  • du -sh * - Klasör bazında boyut.
  • wmic logicaldisk get size,freespace,caption - Windows disk bilgisi.

4.3. Süreç Yönetimi

İşlemWindows CMDPowerShellmacOS / LinuxAçıklama
İşlemleri listeletasklistGet-Processps -eAktif süreçleri listeler.
İşlem sonlandırtaskkill /IM notepad.exe /FStop-Process -Name notepadkill -9 PIDBelirli süreci kapatır.

4.4. Kaynak İzleme

  • top - Gerçek zamanlı CPU/RAM izleme.
  • htop - Renkli kaynak monitörü (Linux).
  • perfmon - Windows Performans Monitörü.
  • vmstat - Bellek ve işlem istatistikleri.

4.5. Ağ ve IP Bilgisi

  • ipconfig / ifconfig - IP yapılandırması.
  • netstat -ano / netstat -tulnp - Aktif bağlantılar.
  • ping 8.8.8.8 - Bağlantı testi.
  • nslookup domain.com - DNS çözümleme.
Bölüm Özeti: Bu bölümde sistem bilgilerini (uname, systeminfo), kaynak durumunu (df, free), işlem yönetimini (ps, kill) ve ağ bağlantılarını (netstat, ping) öğrendin.

5. Ağ, internet ve bağlantı komutları

Bu bölüm, bilgisayarın ağ bağlantılarını, IP yapılandırmalarını, port dinlemelerini ve bağlantı sorunlarını yönetmek için kullanılan temel komutları kapsar.

5.1. Ağ Yapılandırması

  • ipconfig /all - Tüm ağ adaptörlerini ve IP bilgilerini gösterir.
  • Get-NetIPAddress - PowerShell ağ adres bilgisi.
  • ip a - Linux IP yapılandırması.

5.2. Ağ Bağlantılarını İzleme

  • netstat -ano - Aktif bağlantılar ve PID bilgisi.
  • ss -tuln - Linux'ta port dinleme durumu.
  • netstat -p tcp - Sadece TCP bağlantılarını gösterir.

5.3. Bağlantı Testi

İşlemWindows CMDPowerShellmacOS / LinuxAçıklama
Ping testiping 8.8.8.8Test-Connection 8.8.8.8ping 8.8.8.8Bağlantı kontrolü.
Traceroutetracert google.com-traceroute google.comPaketlerin geçtiği rotayı gösterir.
DNS sorgusunslookup openai.comResolve-DnsName openai.comdig openai.comDNS çözümleme testi.

5.4. DNS ve Ağ Servisleri

  • ipconfig /flushdns - DNS önbelleğini temizler.
  • systemd-resolve --flush-caches - Linux DNS temizleme.
  • dig openai.com +trace - DNS çözüm zincirini görüntüler.

5.5. Ağ Paylaşımları

  • net use - Ağ sürücülerini listeler.
  • mount -t cifs //sunucu/paylasim /mnt/hedef - SMB paylaşımlarını bağlar.
  • umount /mnt/hedef - Paylaşımı kaldırır.

5.6. Gelişmiş Ağ Araçları

  • nc -zv IP PORT - Port taraması yapar.
  • curl https://example.com - HTTP isteği gönderir.
  • wget URL - Dosya indirir.
  • tcpdump -i eth0 - Ağ trafiğini analiz eder.
Bölüm Özeti: Bu bölümde IP yapılandırma (ipconfig, ifconfig), ağ teşhisi (ping, traceroute), bağlantı izleme (netstat, ss) ve port testleri (nc) konularını öğrendin.

6. Paket, yazılım ve güncelleme yönetimi

Her işletim sisteminin kendine özgü paket yöneticisi vardır. Bu bölümde, Windows, macOS ve Linux için yazılım yükleme, güncelleme ve kaldırma komutlarını öğreneceksin.

6.1. Paket Yöneticileri Genel Görünüm

PlatformYöneticilerAçıklama
Windowschoco, winget, scoop3. parti yazılım yöneticileri
macOSbrewHomebrew en yaygın araçtır
Linuxapt, yum, dnf, pacmanDağıtıma göre farklılık gösterir

6.2. Paket Arama ve Kurulum

  • apt search paket / brew search paket / choco search paket - Paket arar.
  • sudo apt install paket / brew install paket / choco install paket -y - Paket yükler.
  • dpkg -i dosya.deb - Dosyadan yükleme (manuel kurulum).

6.3. Paket Kaldırma

  • sudo apt remove paket - Paketi kaldır.
  • brew uninstall paket - macOS'ta kaldır.
  • choco uninstall paket - Windows'ta kaldır.

6.4. Güncelleme Yönetimi

  • sudo apt update && sudo apt upgrade - Linux sistem güncellemesi.
  • brew update && brew upgrade - Homebrew güncellemesi.
  • choco upgrade all -y - Tüm Windows paketlerini günceller.
Bölüm Özeti: Paket yöneticilerini (apt, brew, choco) kullanarak yazılım yüklemeyi, kaldırmayı ve güncellemeyi öğrendin.

7. Çıktı yönlendirme, loglama ve boru hatları

Terminalde her komut bir çıktı üretir. Bu çıktı ekrana yazılabilir, dosyaya kaydedilebilir veya başka bir komuta aktarılabilir. Bu sistemin temeli stdout (çıktı), stderr (hata) ve stdin (girdi) akışlarına dayanır.

7.1. Temel Operatörler

OperatörAçıklamaÖrnek
>Çıktıyı dosyaya yazar (üzerine yazar)ls > liste.txt
>>Dosyanın sonuna eklerecho "Yeni" >> log.txt
2>Hata çıktısını yönlendirirpython app.py 2> hata.txt
&>Tüm çıktıları yönlendirircommand &> full.log

7.2. Boru (Pipe) Kullanımı

  • ls | grep .txt - Tüm .txt dosyalarını filtreler.
  • ps aux | grep chrome - Belirli işlemi bulur.
  • dmesg | less - Çıktıyı sayfa sayfa gösterir.

7.3. Loglama

  • command > log.txt - Çıktıyı kaydeder.
  • command &> full.log - Hem hata hem çıktıyı loglar.
  • echo "$(date): işlem tamamlandı" >> app.log - Zaman damgası ekler.

7.4. Metin Filtreleme ve İşleme

  • grep "error" log.txt - Hata satırlarını bul.
  • sort dosya.txt - Satırları sırala.
  • wc -l - Satır say.
  • cut -d ":" -f1 - İlk sütunu al.
  • awk '{print $1}' - İlk sütunu yazdır.
Bölüm Özeti: Komut çıktısını yönlendirmeyi (>, 2>), filtrelemeyi (grep, awk) ve log tutmayı öğrendin.

8. Betikler, otomasyon ve zamanlama

Bu bölüm, komutları toplu halde çalıştırmayı, otomatikleştirmeyi ve zamanlanmış görevler oluşturmayı öğretir. Bash (Linux/macOS) ve PowerShell (Windows) örnekleriyle birlikte gelir.

8.1. Betik Temelleri

  • Bash: #!/bin/bash başlığıyla başlayan .sh dosyaları.
  • PowerShell: .ps1 uzantılı dosyalar.
  • Oluşturmak için: nano script.sh veya notepad script.ps1.

8.2. Değişkenler ve Parametreler

  • Bash: isim="Ali" → echo $isim
  • PowerShell: $isim = "Ali" → Write-Output $isim
  • Argümanlar: Bash'te $1, PowerShell'de $args[0]

8.3. Koşullar ve Döngüler

TürLinux/macOSPowerShellAçıklama
ifif [ -f dosya ]; then echo "Var"; fiif (Test-Path "dosya") { "Var" }Dosya kontrolü.
forfor i in *.txt; do echo $i; doneforeach ($i in Get-ChildItem *.txt) { $i }Döngü örneği.
whilewhile true; do date; sleep 5; donewhile ($true) { Get-Date; Start-Sleep 5 }Sürekli çalıştırma.

8.4. Görev Zamanlama

  • schtasks /create /tn "yedek" /tr "C:\yedek.ps1" /sc daily /st 09:00 - Windows'ta görev zamanlayıcı.
  • crontab -e → 0 9 * * * /home/user/yedek.sh - Linux'ta günlük görev.
  • @reboot - Sistem açıldığında çalıştır.

8.5. Loglama ve Hata Yönetimi

  • bash script.sh > out.log 2> err.log - Hataları ayrı logla.
  • .\script.ps1 *> full.log - PowerShell'de birleşik log.
  • set -e - Hata durumunda betiği durdurur.
Bölüm Özeti: Betik oluşturmayı, koşul/döngü yapılarını ve görev zamanlama araçlarını (cron, schtasks) öğrendin.

3. File permissions, ownership and access management

This section covers the terminal commands used to manage user permissions and to control who can read or change files. Although the permission system differs between Windows, macOS and Linux, the basic idea is the same: read, write and execute permissions.

9. Debugging, security and common errors

The terminal is powerful; a wrong command can have irreversible consequences. This section covers safe working practices and how to recognise and fix errors.

9.1. Dangerous Commands

  • rm -rf / - 🔥 Deletes the entire system.
  • chmod -R 777 / - 🚫 Gives everyone full access (dangerous).
  • dd if=/dev/zero of=/dev/sda - 💀 Wipes the disk.
Warning: Think twice before working with root privileges. A single wrong command can wipe the whole system.

9.2. Reading Command Errors

ErrorDescriptionSolution
command not foundThe command is not on the systemInstall it with the package manager (sudo apt install).
Permission deniedPermission errorAdd sudo or change the permissions (chmod +x).
No such file or directoryIncorrect file pathCheck the path.

9.3. Debugging Techniques

  • bash -x script.sh - Step-by-step tracing.
  • Set-PSDebug -Trace 1 - PowerShell script tracing.
  • echo $VAR - Show a variable's value.
  • set -e - Stop the script when an error occurs.

9.4. Log and Monitoring Files

  • /var/log/syslog - Linux system logs.
  • journalctl -p 3 -xe - Recent critical errors.
  • eventvwr.msc - Windows Event Viewer.

9.5. Writing Safe Scripts

  • Make a backup with cp before critical operations.
  • Use mv or trash instead of rm.
  • Quote your variables: "$VAR".
  • Add logging to scripts: echo "$(date): işlem yapıldı" >> script.log
